FAQ

Plain answers before someone bounces.

Is DystopAI a cloud SaaS?

DystopAI starts as a local-first desktop command center. The website is for marketing, signup, docs, downloads, accounts, and updates.

Can agents act without approval?

They can prepare and execute configured workflows, but high-impact actions should stay behind approval gates, especially purchases, account changes, outbound messages, file deletion, GitHub pushes, and deployments.

What makes it different from a chatbot?

DystopAI gives agents lanes: roles, models, workspaces, tools, missions, schedules, runtime visibility, plugins, and proof reports instead of one messy chat history.

Can people control it through other channels?

The desktop app is the center. Compatible plugins can route commands and updates through communication channels such as web chat, SMS, voice, team chat, webhooks, or future channel plugins.
