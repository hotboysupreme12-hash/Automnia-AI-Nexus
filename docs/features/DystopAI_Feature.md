## What Is DystopAI, Really?

DystopAI is a **standalone desktop command center** built for the OpenClaw agent runtime. It's an Electron-based control surface that turns AI models from any major provider into a coordinated team that works for you.

Here's what makes it different:

- **Multi-Model Nexus** — Run DeepSeek, Google Gemini, OpenAI, Anthropic, and open-source models in the same party. They compete. They collaborate. You command.
- **Agent Recruitment** — Create full agent personas with markdown doctrine files — identity, soul, tools, memory, and mission prompts. Each agent has a distinct character and lane.
- **Party System** — Deploy multiple agents at once in a "party." They each get their own lane. You watch them work in parallel.
- **Mission System** — Define structured missions with steps, timelines, and success criteria. Deploy to one agent or the whole party. Track progress in real time.
- **Live Monitor** — Watch agent turns, gateway health, session state, and runtime logs. Nothing is hidden. You see exactly what's happening.
- **Plugin Gateway** — Enable ClawTalk for voice calls, SMS, and phone outreach. Your agents don't just chat — they call people.
- **Skill Library** — Install skills from ClawHub. Build reusable workflows. Teach agents new capabilities without rewriting their doctrine.

## The Engine Room

Under the hood, DystopAI is serious architecture:

| Component | What It Does |
|---|---|
| **AgentManager** | Recruits, configures, and maintains agent personas with MDS profiles |
| **SoulEngine** | Reads and interprets agent doctrine files — identity, soul, mission, memory |
| **HeartbeatController** | Keeps agents alive between turns — task-aware continuity |
| **MissionOrchestrator** | Coordinates multi-agent missions with step tracking and status sync |
| **CoordinationBus** | Routes messages between agents in parallel deployments |
| **RuntimeComposer** | Assembles agent execution environments from plugins, skills, and models |
| **MDSValidator** | Validates agent metadata against the MDS schema before deployment |

The server backend uses TypeScript with Express, SQLite for persistence, and WebSocket for live streaming. The frontend is React/TypeScript with Tailwind, Framer Motion, and a dark cyber-luxury UI that looks like something out of a movie.
