# Automnia AI Next 30-Point Production Plan

This planning note tracks the next public beta readiness milestones for Automnia AI.

The work focuses on hosted CI evidence, packaged beta behavior, backend service extraction, browser and filesystem hardening, architecture budgets, and UI stability.

Packaged beta evidence must include the core screenshot surface set: Agents, Missions, Monitor, Plugins, Settings, and Agent Editor across desktop, compact, and mobile viewports.

For current implementation status, see `docs/NEXT_30_POINT_LEDGER.md`.
